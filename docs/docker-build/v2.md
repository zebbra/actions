# `docker-build/v2` - Docker build with optional smart GHA cache, generic/custom tagging and labels

Build/push Docker image with configurable GHA cache, generic/custom tagging and labels

## Quick usage
```yaml
jobs:
  example:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: zebbra/actions/docker-build@docker-build/v2
      # with:
      #   <input_name>: <value>
```

## Inputs
| Name | Required | Default | Description |
| ---- | -------- | ------- | ----------- |
| `image_name` | true |  | Fully qualified image name to tag/push (e.g., quay.io/org/app) |
| `context` | false | `.` | Build context |
| `file` | false | `./Dockerfile` | Dockerfile path |
| `target` | false |  | Optional Docker build target (multi-stage target name) |
| `platforms` | false |  | Optional platforms (comma-separated) for multi-arch builds |
| `push` | false | `false` | Push the built image to the registry (`true`/`false`). Requires at least one tag to be enabled/provided (e.g., `include_tag_sha`, `include_tag_ref`, `latest_tag_on_main_push`, `nightly_tag_on_develop_push`, or `tags`). |
| `load` | false | `false` | Load the built image into the local Docker daemon (`true`/`false`). Useful for local testing or when you need the image available locally after build. Note: Cannot be used together with multi-platform builds (`platforms` input). |
| `include_tag_sha` | false | `false` | Include a tag based on the commit SHA (`true`/`false`). |
| `include_tag_ref` | false | `false` | Include a tag based on the branch name (`true`/`false`). |
| `latest_tag_on_main_push` | false | `false` | Add `latest` tag when pushing from `main` (`true`/`false`). |
| `nightly_tag_on_develop_push` | false | `false` | Add `nightly` tag when pushing from `develop` (`true`/`false`). |
| `tags` | false |  | Additional docker/metadata-action tag rules (multiline). Appended verbatim to the metadata-action `tags` input. Examples: `type=raw,value=1.2.3` `type=raw,value=one-tag-to-rule-them-all` `type=semver,pattern={{major}}.{{minor}}` |
| `description` | false |  | Value for `org.opencontainers.image.description` label |
| `extra_labels` | false |  | Extra labels (multiline `key=value`), appended verbatim |
| `build_args` | false |  | Additional build-args (multiline `KEY=VALUE`), appended verbatim |
| `cache_from_overrides` | false |  | Override `cache-from` lines (multiline). If set, skips `smart_cache`. |
| `cache_write_scope` | false |  | Scope name for `cache-to` (defaults to current branch). Use to control where cache is written. |
| `smart_cache` | false | `true` | Enable smart `cache-from` heuristic (head, base, develop, main). Ignored if `cache_from_overrides` is provided. |
| `secrets` | false |  | Additional BuildKit secrets (one per line). Examples: `id=GIT_AUTH_TOKEN,env=GITHUB_TOKEN` or `id=mysecret,src=/path/to/file` |

## Outputs
| Name | Description |
| ---- | ----------- |
| `tags` | Generated Docker image tags |
| `digest` | Image digest |
