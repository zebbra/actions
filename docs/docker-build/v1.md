# `docker-build/v1` - Docker build with optional smart GHA cache, generic/custom tagging and labels

Build/push Docker image with configurable GHA cache, generic/custom tagging and labels

## Quick usage
```yaml
jobs:
  example:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: zebbra/actions/.github/actions/docker-build@docker-build/v1
      # with:
      #   <input_name>: <value>
```

## Inputs
| Name | Required | Default | Description |
| ---- | -------- | ------- | ----------- |
| `image_name` | true |  | Fully qualified image name to tag/push (e.g., quay.io/org/app) |
| `context` | false | `.` | Build context |
| `file` | false | `./Dockerfile` | Dockerfile path |
| `target` | false |  | Optional Docker build target (multi-stage target name) |
| `platforms` | false |  | Optional platforms (comma-separated) for multi-arch builds |
| `push_on_branches` | false | `main,develop` | Comma-separated list of branch names that are allowed to push. Ignored if `push` is `true`. |
| `push` | false |  | Force push regardless of branch rules (`true`/`false`). If `true`, overrides `push_on_branches`. |
| `include_tag_sha` | false | `true` | Include a tag based on the commit SHA (`true`/`false`) |
| `include_tag_ref` | false | `true` | Include a tag based on the branch/ref (`true`/`false`) |
| `tag_latest_branch` | false | `main` | Branch name that should produce the `latest` tag |
| `tag_latest_name` | false | `latest` | Exact tag to use when on `tag_latest_branch` |
| `tag_nightly_branch` | false | `develop` | Branch name that should produce a `nightly` tag |
| `tag_nightly_name` | false | `nightly` | Exact tag to use when on `tag_nightly_branch` |
| `tag_custom` | false |  | Additional docker/metadata-action tag lines (multiline), appended verbatim |
| `description` | false |  | Value for org.opencontainers.image.description label |
| `extra_labels` | false |  | Extra labels (multiline key=value), appended verbatim |
| `build_args` | false |  | Additional build-args (multiline KEY=VALUE), appended verbatim |
| `build_arg_name_for_version` | false |  | If set, injects the computed `version` into build-args as NAME=VALUE |
| `version` | false |  | Version to inject (if `build_arg_name_for_version` is set). Defaults to the current branch name. |
| `cache_from_overrides` | false |  | Override cache-from lines (multiline). If set, skips `smart_cache`. |
| `cache_write_scope` | false |  | Scope name for cache-to (defaults to current branch). Use to control where cache is written. |
| `smart_cache` | false | `true` | Enable smart cache-from heuristic (head, base, develop, main). Ignored if `cache_from_overrides` is provided. |
| `secrets` | false |  | Additional BuildKit secrets (one per line). Examples: `id=GIT_AUTH_TOKEN,env=GITHUB_TOKEN` or `id=mysecret,src=/path/to/file` |

## Outputs
| Name | Description |
| ---- | ----------- |
| `tags` | Generated Docker image tags |
| `digest` | Image digest |
