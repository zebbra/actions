# `check-semver/v2` - Check SemVer on Branch

A GitHub Action that checks SemVer integrity on a branch

## Quick usage
```yaml
jobs:
  example:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: zebbra/actions/check-semver@check-semver/v2
      # with:
      #   <input_name>: <value>
```
